# The Platform Rate is set by hand, not from a rate feed

The Admin types in the Platform Rate instead of the platform fetching it from an exchange-rate service. Vendors in Erbil price against the market rate (about 1,575 IQD per USD on 1 October 2026), while rate services report the official rate (1,300), so an automatic feed would make every Converted Price about 20% lower than what the shop actually charges.

Do not replace this with a rate API unless the source demonstrably tracks the Erbil market rate.
