## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Design skills

Before any design work on the dashboard or the Shopper app (designing, redesigning, critiquing, polishing, motion), read `docs/agents/design-skills.md`: Impeccable, Taste and Emil Kowalski's skills each lead one area.
