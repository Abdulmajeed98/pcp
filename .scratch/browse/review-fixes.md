# The code review's fixes

The code review of `browse/integration` at `a8efcc3` (tickets 01 to 13 and 15 merged) found six things against the Standards, with seven smells, and six against the Spec, and the run's follow-ups added eighteen more for it. The orchestrator's triage, in the owner's checkout at `.taste-skill/browse-briefs/code-review.md`, said what to do with each; the owner answered the two that waited on them on 7 November 2026, "Keep both". This file records how each was dealt with, on the branch `browse/review-fixes`, one line to a finding.

## Comments

### 7 November 2026: the code review's fixes

**The Spec's findings.**

2. **Spec 2, two faults no ticket planted.** Planted on `36e3113` and taken out by the inverse edit, each failing its own check (the table below): a parameter added to `GET v1/visible-parts` without `pnpm api-client:write` failed the API's test of its own description, and the Arabic name of the socket filter removed failed the check of the language files.
