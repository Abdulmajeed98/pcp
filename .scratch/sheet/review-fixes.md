# The code review's fixes: the `sheet` module

The code review of `sheet/integration` since `b993282` ran on 18 November 2026, on `93622bc`, along two axes, Standards and Spec. It found three things against the Spec, one partly built and two that looked wrong, and a count in the spec's text that was wrong; and thirteen against the Standards, four of them hard (documented standards) and nine judgement calls. The orchestrator's brief, in the owner's checkout at `.taste-skill/sheet-briefs/review-fixes.md`, said what to do with each, with both reports beside it, and took the decisions that waited on the owner under the owner's standing instruction. This file records how each was dealt with, on the branch `sheet/review-fixes`, one line or a short paragraph to a finding. It ticks no ticket and leaves every Status line alone; ticket 05 writes the MVP spec's **The sheet module's conventions**. Where a fix changes what the spec says, the spec is amended in the same commit as this record, each passage marked "Corrected by the code review of 18 November 2026".
